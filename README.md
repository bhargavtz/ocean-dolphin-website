## 🌟 Modern 2026 Architecture & Key Features

### 1. 🎨 Apple & Google Human Interface Design System
- **Tailwind CSS v4 Engine**: Zero-bloat, lightning-fast utility architecture replacing legacy 2,300+ lines of conflicting CSS.
- **Glassmorphic Acrylics**: Multi-layer backdrop blurs (`backdrop-blur-xl bg-white/90`), subtle depth shadows, and micro-elevation transitions (`hover:-translate-y-0.5`).
- **Typography**: Clean, high-legibility **Plus Jakarta Sans** paired with refined tracking and contrast.

### 2. 🤖 Interactive AI Visa & University Eligibility Matcher
- **3-Step Intelligent Diagnostic Tool**:
  1. Target Destination Selection (Flags & Country Specs)
  2. Academic Qualification (12th / Bachelor's / Master's / Diploma + GPA/Percentage)
  3. English Proficiency (IELTS 6.5+, PTE 58+, Duolingo, or Without IELTS / MOI route)
- **Instant Live Evaluation**: Calculates match percentage (e.g. `96%`), eligible 2026–2027 intakes, estimated post-study work visa length (PSW / PGWP), and scholarship potential.
- **1-Click WhatsApp Lead Generator**: Automatically packages student diagnostics into prefilled WhatsApp messages for immediate counselor response.

### 3. 🍎 Apple-Style Interactive Country Comparison Matrix
- Segmented control pill tabs to compare **🇬🇧 UK**, **🇨🇦 Canada**, **🇺🇸 USA**, **🇦🇺 Australia**, and **🇩🇪 Germany** side-by-side (work permits, tuition costs, top universities, and minimum IELTS/PTE scores).

### 4. 🔔 Live Activity Dynamic Visa Approval Toasts
- Floating glassmorphic toast notification (bottom-left) broadcasting real-time student acceptance and visa grants across top global universities.

### 5. 🎭 Animated Micro-Icons (Lordicon CDN)
- High-quality interactive animated vector icons across all core service cards (Globe, University Cap, IELTS Book, PTE Simulation, Passport, and Education Loan).

### 6. 🌐 Direct AI Search Engine & SearchGPT Optimization
- **`sitemap.xml` & `robots.txt`**: Configured with dedicated crawl directives for **GPTBot (SearchGPT)**, **PerplexityBot**, **Applebot**, **Gemini**, and **Google-Extended**.
- **Schema.org JSON-LD**: Comprehensive structured data for `EducationalOrganization`, `LocalBusiness` (with geo-coordinates for Mota Varachha, Surat), and `AggregateRating` (4.9/5 stars).

## 💻 Local Development & Setup

### Prerequisites
- Python 3.8+ **OR** Node.js installed on your machine.

### Quick Start (Local Server)

1. **Clone the repository**:
   ```bash
   git clone https://github.com/bhargavtz/ocean-dolphin-website.git
   cd ocean-dolphin-website
   ```

2. **Start the local HTTP server**:
   ```bash
   # Using Python 3:
   python3 -m http.server 8000

   # Or using Node:
   npx serve .
   ```

3. **Access the platform**:
   Open **[http://localhost:8000](http://localhost:8000)** in any modern web browser.
